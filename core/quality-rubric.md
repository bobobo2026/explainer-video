# 质量评分表（静帧联系表和成片出来后逐项打分，任何一项低于 2 分就改，不交付）

先把你的联系表和对应风格的参考联系表并排看：`styles/handdrawn/assets/reference/00_整片联系表.jpg` / `styles/realistic/reference/00_联系表.jpg`。

## 通用项（两种风格都打）
| 维度 | 0 分 | 2 分（及格） | 3 分（参考帧水平） |
|---|---|---|---|
| 事实 | 有凭记忆写的数字/细节 | 数字都有出处 | 出处 + 截至日期都写清，不确定的不说 |
| 比喻 / 素材 | 只有文字和图标堆砌 | 每镜一个物件比喻或真实素材 | 比喻带「动作」（被驯服、散开、倒推解锁），真实截图上有圈注 |
| 卡点 | 元素按镜头开始平均出现 | 主要元素卡关键词 | 每个名词/动词都对应一个出现时刻，听到就看到 |
| 持续运动 | 画完就静止 | 每镜一个小动作 | ≥2 种同时进行（漂浮 + 计数 + 光点流动…） |
| 角色 | 没有角色 | 有角色 | 角色有表情/口型，随剧情变化 |
| 重音 | 没有 / 每句都在强调 | 每段 2–4 个盖章 | 落在论点落点词上，配闷响 |
| 版式 | 压字、裁切、拥挤、单字掉行 | 不压字，留白 ≥30% | 主次清晰，字幕标黄词和画面强调色一致 |
| 字幕 | 没有 / 和读音对不上 | 和口播同步 | 逐字亮起，关键词标黄，断行自然 |
| 声音 | 机械 TTS / 没有音乐 | 自然 TTS + 音乐给人声让路 | 真人或高质量 TTS；音效和画面用同一个时钟 |
| 响度 | 忽大忽小 | -16~-14 LUFS | -14 LUFS，TP ≤ -1.5 dB |

## 手绘风格追加
| 手绘感 | 矢量图形一次性出现 | 线稿逐笔描出 | 笔尖/马克笔跟随（penOn），线条有抖动和排线 |
| 镜头 | 硬切 | 有转场 | zoom/scroll/curl/erase 交替 + 局部推近 |

## 拟真风格追加
| 真人感 | 静态头像 | 主播口型同步 + 眨眼 | 再加点头、呼吸、挑眉；开头/结尾大号出镜 |
| 真实素材 | 没有截图 | 有截图 | 截图放在设备外壳里，有镜头滚动/推近 + 手绘圈注 |
| 质感 | 纯平背景 | 有阴影/渐变 | 手持微晃 + 颗粒 + 暗角 + 转场模糊 |
| 竖屏安全区 | 内容被平台 UI / 小窗挡住 | 主要内容在安全区内 | 标题、主画面、字幕三区分明，底部只放氛围元素 |

自评要写出来，例如：「case 场景 卡点 1 分：拍立得等到 DX Ball 才出现，前 1.5 秒画面是空的 → 改成场景一开始就出现」。
**不要拿「时长对、文件能播、mean_volume 正常」当质量结论**，那只是能交付的最低技术条件。
