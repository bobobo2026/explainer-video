# 各平台文案模板（交付时和成片一起给）

通用：只用事实清单里的数字，标注数据截至的日期；**抖音和小红书正文不放外链**（可能被限流），链接放 B站简介、评论区或 X。

## 抖音（标题 ≤30 字 + 3–4 行正文 + 6–8 个话题）
标题：数字 + 反差 + 一句话价值。例：半年 24 万星！GitHub 爆火项目 REA，让 AI 帮你“逆向一切”
正文：一个问题钩子 → 它做了什么（一句）→ 结果（一句）→ 评论区提问👇
话题：#AI #GitHub #开源项目 #<领域> #程序员 #AI工具 #<相关产品>

## 小红书（标题 ≤20 字，带 emoji；正文按 emoji 小标题分段）
🍳 是什么（比喻）/ 🔌 做了什么 / 💬 怎么用 / 📦 能做什么 / 🎮 案例数据 / ⚙️ 上手 / ⚠️ 提醒 → 结尾提问。标签 8–10 个。
封面：建议用视频里大数字那一帧，或主播出镜那一帧。

## B站（标题 ≤80 字，用【】标栏目；简介里放章节时间戳 + 项目链接 + 安装命令 + 数据日期）
章节时间戳直接从 timeline.json 各场景首句的 start 取，格式 mm:ss。标签 8–10 个。

## 视频号（2–3 行 + 3–4 个话题），偏稳重，少用网络梗。

## X（英文 ≤280 字符）
Hook line → 一句数字 → 怎么做（一句）→ 安装命令 → “Made a 90-sec explainer 👇”。
