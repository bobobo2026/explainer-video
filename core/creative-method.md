# 创作方法：把抽象概念画成一眼能懂的画面

## 1. 比喻翻译表（本项目实测好用）
| 抽象概念 | 画面 |
|---|---|
| 概念太多、分不清 | 名词纸条从天而降、乱抖，一个橙色大问号一笔描出 |
| 只能在对话框里 | 窗户（外框+十字窗棂），机器人从窗里探头；对话框被橙圈圈住，和电脑之间一道虚线墙 + 大叉 |
| 复制粘贴来回搬 | 纸片在两台设备间抛物线来回飞，旁边用「正」字计数 |
| 工具驾驭 AI | 马蹄铁=马具；机器人乱蹦=烈马；橙色缰绳连上后机器人安静微笑 |
| 能看见文件 | 放大镜扫过文件图标，扫到的变橙 |
| 能自己动手 | 鼠标把文件拖进文件夹，落点橙色涟漪 |
| 下命令等结果 | 深色终端里逐字打出命令 → 「✓ 已生成」→ 文件弹出 → 盖章「搞定」 |
| 什么都能做 | 任务卡片网格，按口播顺序逐个弹出+打勾，然后整体变淡，大字结论压上去 |
| 局限：被绑在电脑前 | 小人坐在桌前，被橙色椭圆圈住 + 一把锁，「出门了怎么办？」 |
| 24 小时在线 | 时钟指针快转 + 「24h」+ 闪烁的在线点 |
| 不用管环境配置 | 齿轮出现 → 橙叉划掉 |
| 当老板/团队 | 戴皇冠的小人 + 「去做事！」气泡，机器人 1→4→12 复制，右下「×12」计数 |
| 角色分工 | 一排卡片，每张一个机器人 + 道具（哑铃/日程/地球/手机） |
| 阶段进阶 | 台阶，每级一个图标+一句话，箭头往上，最高一级戴皇冠 |
| 迷雾变清晰 | 灰色波浪线盖住机器人，说到「清晰」时向两边散开，机器人笑 |

规律：**名词→物件，动词→动作，程度→数量/大小，对比→左右分屏+中间虚线，结论→印章**。

## 2. 镜头版式（手绘横屏 1920×1080，世界坐标每镜一块；拟真竖屏版式见 styles/realistic/GUIDE.md）
- 标题行：`y0+90~140`，左起 `tag('@B')` + 标题，核心词用 `blockWord`。
- 主体：左右两栏（对比/因果）或三栏卡片（并列）或中心大物件（定义）。
- 底部结论：`y0+760~830`，印章放右下或正下。`y0+860` 以下是字幕区，不放东西。
- 留白 ≥30%。一镜元素多于 6 个就拆镜。

## 3. 节奏规则
- 元素出现提前 0.1–0.3 秒于关键词（`M('词') - 0.2`），线稿描绘 0.3–0.8 秒，文字每字 0.06–0.08 秒。
- 每镜开头 0.1–0.5 秒内必须有东西开始画（不然像卡住）。
- 重音（印章+震屏+闷响）每段 2–4 个，放在每个论点的「落点」词上。
- 转场交替使用 zoom / scroll / curl（翻页）/ erase（橡皮擦），大段落切换用 curl 或 erase。
- 段尾留一句灰色预告「下一种：搬进云端 →」，把段与段串起来。

## 4. 质检清单（每次看静帧都过一遍）
1. 有没有字没写完（seq 的字数不对）、被裁、压字幕？
2. 元素重叠？中英文混排宽度用 tw() 算了吗？
3. 每镜能一句话说出画的是什么？比喻有没有歧义（像别的东西）？
4. 推镜（CAM z>1）有没有把边上元素推出画面？
5. 皇冠/帽子这类贴在头上的物件，位置按 `makePerson` 头顶 = 脚底 − 232×s − 40×s 算。
6. 每镜有没有持续小动作？

## 5. 拟真风格补充（REA 那期实测）
| 抽象概念 | 画面 |
|---|---|
| 爆火 / 增长 | 真实 GitHub 页面滚动到 stars → 推近 → 手绘圈注；大号计数器 0→239.4k |
| 名字缩写 | 三个橙色字母块砸下 → 各自展开成单词 → 盖章中文意译 |
| 逆向 / 倒推 | 菜（成品）+ 菜谱打叉 + 大厨尝一口 → 配料依次飞出；App 图标 ✓ / 源代码 🔒 → 弯箭头倒推 → 锁消失、代码变清晰 |
| 以前很难 | 真实专业软件截图慢慢平移 + 程序员流汗 + 日历「第 1→5 天」翻页 |
| 接入 / 插件 | 上中下三层：AI 助手卡 → 橙色插头块 → 工具卡，虚线 + 流动光点 |
| 一句话就能用 | 聊天窗口里跟着口播逐字打字 → 发送 → 「正在调用…」转圈 |
| 有证据、不瞎猜 | 步骤转圈 → ✓；结论/证据/不确定三张彩色边卡片；盖章「不靠猜」 |
| 隐私 / 本地 | 电脑 + 盾牌，云朵被红线划掉 |
| 案例硬数据 | 拍立得相框 + 声波环；计数器 + 进度条；63 个字节格子依次变绿；盖章「一模一样 ✓」 |
| 上手简单 | 终端逐字输入命令，输出逐行 ✓ |
规律：**能用真实截图就用真实截图，再用手绘圈注指给观众看**；emoji（Noto Color Emoji）当道具又快又真实。
